# Projeto Final - Análise Preditiva de Microcefalia

Este projeto contém a implementação de modelos de aprendizado de máquina para classificar casos de microcefalia com base em dados do Ministério da Saúde.

## Como Executar

1.  Crie e ative um ambiente virtual.
2.  Instale as dependências: `pip install -r requirements.txt`
3.  Execute os scripts na pasta `src/`, começando por `preparar_dados.py`.
